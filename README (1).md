# UFI001C OpenWrt 25.12.5 · v3.1.2 Setup

[Страница проекта](../README.md) · [Установка и обновление](INSTALL-RU.md) ·
[Состояние и ограничения](PROJECT-STATE.md) · [Проверки](VALIDATION-v3.1.2.md)

Исходники сборки для UFI001C: закреплённые версии OpenWrt/OpenStick, Podkop,
podkop-engine XHTTP r12, радио UFI001BC 20211121, сетевые проверки, USB-установщик.
Workflow `.github/workflows/openwrt25-ufi001c.yml` собирает образы, проверяет их
и создаёт один ZIP для Releases. Для уже установленной v3.1.1 есть live-правка
`hotfix/`; она не перепрошивает устройство и не меняет ядро.

В v3.1.2 исправлены добавление секций после удаления последней, обработка пустых
секций, автоматический выбор DNS-прокси и разделение локальной/внешней диагностики
FakeIP. Это подготовленные исходники; статус конкретного образа виден в Actions
и отчётах внутри его архива. Аппаратная приёмка обязательна до статуса stable.
