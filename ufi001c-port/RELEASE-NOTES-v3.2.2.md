# UFI001C v3.2.2 Clean

Рабочая схема из отдельного патча включена в прошивку: Яндекс 77.88.8.8 TCP:53
напрямую разрешает только адреса прокси; Cloudflare 1.1.1.1 DoH:443 работает
через выбранную прокси-секцию Podkop. Адрес прокси имеет независимый bootstrap,
поэтому его первое разрешение не зависит от уже поднятого туннеля Cloudflare.
Автоматического перехода обычных DNS-запросов на прямой Яндекс нет.
При отказе удалённого прокси этот режим DNS тоже будет недоступен.

В Podkop → Настройки добавлены «Cloudflare DoH через прокси» (включён по
умолчанию), выбор прокси-секции и «Проверить Cloudflare». Автовыбор предпочитает
настроенную dns_only, затем первую настроенную прокси-секцию. Кнопка проверяет
настоящий RFC 8484 DNS-ответ через применённый маршрут, с проверкой TLS.
Локальный кэш, отключённый режим и ошибка RPC не дают ложного успеха.
При выключении режима доступны ручные DNS-настройки Podkop.

Диагностика Podkop больше не проверяет заблокированный прямой DoH в этом режиме.
CHECK-LTE.cmd определяет обе чистые версии, проверяет фактический DNS-путь и
локальный FakeIP; старые удалённые службы ему не нужны. В скриптах отдельного
старого патча исправлено сохранение кода SSH: цифра перед >> ошибочно
воспринималась CMD как номер дескриптора. Старый патч привязан к неизменённой
копии программы v3.2.1 и не предназначен для установки поверх v3.2.2.

Найдена и исправлена ошибка обработки неуспешной генерации конфигурации:
Podkop больше не устанавливает перехватывающие правила и не переводит dnsmasq
на остановленный резолвер после такой ошибки. Проверенная конфигурация создаётся
до правил; ошибка возвращается вызывающему коду. Фоновых восстановителей и
перезапуска Wi-Fi, LTE или всей сети эти изменения не добавляют.

Сохранены предыдущие исправления первого подключения dnsmasq и пустого шаблона
main, FakeIP 198.18.0.0/15 и его кэш. Ссылка, UUID, путь и параметры XHTTP/extra
пользователя не заменяются. Header uplink, x-edge-data и chunk 4000 проверяются
отдельными тестами. Профиль LTE прежний: B1/B3/B5/B8/B38/B39/B40/B41;
B7/B20 остаются исключены по прежним данным об RF-сбоях.

Версии базы не менялись: OpenWrt 25.12.5, Podkop 0.7.24
(da8bd40983aaab4d29614d38c8d6214d0a217e3e), podkop-engine 1.13.21-r12.
Это персональный порт UFI001C на исходниках OpenWrt, а не официальный образ
поддерживаемой проектом платы. XHTTP-движок — upstream-форк sing-box.
Манифест clean/podkop-upstream.json хранит исходные хэши всех 26 файлов Podkop
и хэши девяти изменённых файлов. Сетевые recovery-службы остаются исключены.

Установщик со стока сохраняет полный бэкап, сверяет точные профили 4/8 ГБ,
радио, индивидуальные NV и обратное чтение. Для установленного OpenWrt
предусмотрена отдельная процедура обновления в INSTALL-RU.md.

Проверки: VALIDATION-v3.2.2.md. Прежний отдельный патч прошёл проверку на модеме
пользователя, но аппаратная приёмка полного нового образа ещё требуется.
