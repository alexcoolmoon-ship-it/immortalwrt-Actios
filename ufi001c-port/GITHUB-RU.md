# Сборка v3.2.1 Clean

Ветка: codex/ufi001c-clean-v3.2.1. Push запускает полный workflow автоматически.

[Открыть Actions](https://github.com/alexcoolmoon-ship-it/immortalwrt-Actios/actions/workflows/openwrt25-ufi001c.yml).
Нужен заголовок **OpenWrt 25.12.5 UFI001C v3.2.1 Clean / Portable USB**.
После Success скачайте артефакт **UFI001C-v3.2.1-USB-Download**. Внутри находится
**UFI001C-OpenWrt-25.12.5-v3.2.1-USB.zip** и SHA256. Это готовый комплект;
Source code ZIP не является прошивкой.

При ручном workflow_dispatch можно включить публикацию проверенного ZIP в Releases.
Неудачный или незавершённый запуск не считается готовой прошивкой.
