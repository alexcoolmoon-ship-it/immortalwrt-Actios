# UFI001C — OpenWrt 25.12.5, проект v2

Это исходники для нашего UFI001C, не готовая прошивка. Полная компиляция v2 и
проверка на устройстве ещё не выполнены. Проверка выбора обязательных пакетов
через make defconfig пройдена. Рабочее радио SIM UFI001BC 20211121 включено.
Индивидуальные modemst1/modemst2/fsg/fsc в проект не входят.

## Кнопка и возврат Wi-Fi сейчас, без новой прошивки

Скачайте `ufi-care.tar.gz` из чата на ПК в Downloads. Подключитесь к рабочей
точке Wi-Fi модема. В командной строке Windows:

```cmd
scp -O "%USERPROFILE%\Downloads\ufi-care.tar.gz" root@192.168.1.1:/tmp/
ssh root@192.168.1.1 "mkdir -p /tmp/ufi-care && tar -xzf /tmp/ufi-care.tar.gz -C /tmp/ufi-care && sh /tmp/ufi-care/install.sh"
```

После INSTALLED коротко нажмите кнопку уже загруженного модема и проверьте:

```cmd
ssh root@192.168.1.1 "logread -e ufi-care"
```

Ожидается `Reset button released after ...s`. Пока этой строки нет, физическая
кнопка не проверена. Сначала нужен тест короткого нажатия.

| Удержание кнопки на работающем модеме | Действие после отпускания |
|---|---|
| Менее 8 секунд | Только запись в журнал |
| 8–19 секунд | Возврат сохранённых сети, Wi-Fi, DHCP и firewall |
| От 20 секунд | Возврат сохранённых файлов /etc/config |

Снимок создаётся один раз при установке. Это возврат сохранённых настроек,
не стирание ext4/прошивки. Пароль root, пакеты, радио и калибровки сохраняются.
Снимок не перезаписывается повторной установкой.

После 90 секунд загрузки сторож начинает проверять точку доступа. Если она
не работает 120 секунд — возвращает сохранённую сеть. При восстановлении
Podkop, sing-box, zapret и отдельные DNS-прокси останавливаются/отключаются,
чтобы не удерживать сломанные DNS и маршруты. Их можно включить снова позже.

Драйвер wcn36xx не объявляет одновременный AP+STA. Здесь реализован возврат
доступа при неудачном переходе в Wi-Fi-клиент, а не добавление AP+STA.
Для намеренного STA-only сначала настройте и проверьте USB Ethernet и SSH
через него. LAN модема и домашний роутер должны иметь разные подсети.
Только после такой проверки можно отключить сторож:

```sh
uci set ufi-care.main.allow_station=1
uci commit ufi-care
```

Кнопка остаётся активной, восстановление отменяет эту опцию.

## Собрать новый образ

1. Распакуйте `ufi-openwrt25-v2-project.zip` на ПК.
2. В репозиторий `alexcoolmoon-ship-it/immortalwrt-Actios` загрузите папки
   `.github` и `ufi001c-port` в корень с заменой файлов. Сохраните коммит.
   Не добавляйте промежуточную внешнюю папку. Радио разбито на два файла
   менее 14 MiB, сборщик соединяет их и проверяет хеш.
3. Actions → **OpenWrt 25.12.5 UFI001C v2** → **Run workflow** → main.
   Нужен новый запуск с новым коммитом, не Re-run старой сборки.
4. После Success скачайте артефакт `UFI001C-OpenWrt-25.12.5` и распакуйте
   в `%USERPROFILE%\openwrt25-v2`.

В артефакте: boot.img, system.img, SHA256SUMS, ACCESS.txt, ufi-install.py,
radio_backup.py. Новый пароль Wi-Fi находится в ACCESS.txt. Архив исходников
нельзя загружать как образ прошивки. Кэш ускорит последующие сборки;
длительность первой полной компиляции заранее не гарантируется.

## Обновить уже прошитый модем

Поддерживается существующая разметка OpenStick нашего UFI001C. Используется
ваша рабочая установка EDL в `%USERPROFILE%\edl` и ранее установленный драйвер.
Удерживая кнопку, вставьте модем в USB компьютера для входа в EDL, отпустите.
Это отличается от удержания кнопки на уже работающем OpenWrt.

В Windows CMD:

```cmd
cd /d "%USERPROFILE%\openwrt25-v2"
"%USERPROFILE%\edl\.venv\Scripts\python.exe" ufi-install.py backup
```

Нужно минимум 10 GiB свободного места на ПК. Команда только читает eMMC,
проверяет GPT, сохраняет полный бэкап с SHA256. Дождитесь BACKUP VERIFIED.
Бэкап содержит индивидуальные данные модема, сохраните его у себя.

Укажите напечатанный путь к свежему emmc.bin:

```cmd
"%USERPROFILE%\edl\.venv\Scripts\python.exe" ufi-install.py update --backup "ПОЛНЫЙ_ПУТЬ_К_БЭКАПУ\emmc.bin"
```

Скрипт проверяет хеши, UFI001C в boot/DTB, существующую разметку, совпадение
GPT и NV подключённого модема со свежим бэкапом. Разворачивает sparse ext4 на
ПК, пишет только rootfs и boot, читает записанное обратно и сравнивает SHA256.
GPT, загрузчик и NV не записываются. Автоматической перезагрузки нет.

После UPDATE VERIFIED отключите USB и подключите без кнопки. Новая сеть:
OpenWrt-25-UFI001C, пароль из ACCESS.txt, LuCI http://192.168.1.1. Задайте пароль
root. Образы заменяют текущие настройки; старая система остаётся в бэкапе.

При остановке сохраните ошибку. Не обходите проверки разметки, хешей или ABI.
`same-build-apks` содержит пакеты именно нового образа: не устанавливайте
его kernel-модули принудительно на старый образ с другим ABI.

## Podkop, DNS, zapret

В образ включены Podkop 0.7.23, русский LuCI, sing-box 1.12.17, zapret 72.13
и модули TPROXY/NFQUEUE, собранные вместе с ядром. Точная причина сообщения
вашего установщика «несовместимость» без полного текста не установлена.
Недостающие зависимости и цикл выбора sing-box исправлены в конфигурации v2.

Podkop настроен на DoH 1.1.1.1 с прямым выходом в интернет: без чужого
прокси-сервера и без активных списков обхода. Отдельный https-dns-proxy не
ставится, у него конфликт с Podkop. Приложения со своими DNS/VPN могут не
использовать DNS модема. После загрузки проверьте Podkop → Диагностика → DNS.
Для проксирования потребуется ваша совместимая ссылка/конфигурация сервера.

Zapret установлен, но перехват выключен до подбора стратегии для МегаФона.
Наличие пакета ещё не означает работающий обход. Диагностика для реально
недоступного сайта выполняется по SSH:

```sh
cd /opt/zapret
sh blockcheck.sh
```

Результат используется для NFQWS_OPT в /opt/zapret/config, затем включаются
NFQWS_ENABLE=1 и сервис. Универсальная стратегия не заявляется. Начинайте
с небольшого списка доменов, не дублирующего маршруты Podkop. Flow offload
выключен для корректного перехвата. Работу двух приложений проверяем на SIM.

## Полный переход с заводской прошивки

Автоматическая смена заводского загрузчика/GPT ещё не готова. `backup`
обеспечивает полный бэкап и извлечение своего радио при наличии заводского
раздела modem. `update` откажет на заводской/неизвестной разметке до записи.
Это не универсальный конвертер. Текущий рабочий экземпляр уже прошёл эту
стадию, повторять её для обновления v2 не требуется.

Для завершения первоначального конвертера нужно отдельно проверить точный
загрузчик и преобразование разметки. Не использовать NV или полный дамп
другого модема. Проверка физической кнопки, возврата AP, DNS и записи через
новый EDL-помощник на устройстве ещё предстоит.
