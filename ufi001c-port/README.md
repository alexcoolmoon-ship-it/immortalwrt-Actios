# UFI001C OpenWrt 25.12.5 · v3.1.5 LTE Recovery

[Страница проекта](../README.md) · [Установка](INSTALL-RU.md) ·
[Изменения](RELEASE-NOTES-v3.1.5.md) · [Проверки](VALIDATION-v3.1.5.md) · [GitHub](GITHUB-RU.md)

Кандидат с исправлением обработки выключенного wwan0, ограниченным
восстановлением IPv4, сохраняемым профилем LTE B1/B3/B7 и возобновляемым полным
бэкапом стокового модема. XHTTP, DoH и загрузки пакетов через прокси сохранены.

Workflow `.github/workflows/openwrt25-ufi001c.yml` собирает и проверяет образы,
затем публикует единый USB-ZIP. Архив исходников сам по себе прошивкой не является.
Аппаратная приёмка ещё нужна. Старые инструкции live-hotfix относятся к старым
версиям и не являются установщиком 3.1.5.
