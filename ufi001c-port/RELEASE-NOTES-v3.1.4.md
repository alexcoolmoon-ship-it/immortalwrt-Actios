# UFI001C v3.1.4 Services · OpenWrt 25.12.5

Кандидат от 12 октября 2026. Скачать готовую сборку: файл
**UFI001C-OpenWrt-25.12.5-v3.1.4-USB.zip** в Assets этого выпуска.
Внутри INSTALL.cmd, образы, проверки и инструкция. Source code не прошивается.

- Добавлен ufi-service-proxy: LuCI/APK, списки и проверка версии Podkop через
  работающий прокси, без скрытого прямого скачивания. TLS и подписи проверяются.
- Podkop обновлён до 0.7.24. Исправлено сочетание правил FakeIP для составных списков.
- Неудачная загрузка списка сохраняет прежний файл и сообщает ошибку. Исправлена
  последняя попытка проверки GitHub и убрана зависимость прокси-загрузки от прямого DNS.
- Сохранены исправления USB-переподключений и DNS через Selector/URLTest из 3.1.3.
- XHTTP остаётся встроенным в podkop-engine 1.13.21-pdk-r12.
- Усилены проверки файлов в готовом rootfs и проверка генератора конфигурации
  на собранном ARM64-движке в Actions.

Для первой установки со стока нужны точный профиль UFI001C и отдельный бэкап
этого экземпляра. USB/EDL, а не Upload заводской веб-панели. Для существующего
OpenWrt — раздел обновления в INSTALL-RU.md. Стоковый INSTALL.cmd здесь не подходит.

Автоматические проверки не заменяют приёмку на модеме. Реальная стабильность Wi-Fi,
LTE, кнопки и новый переход второго экземпляра со стока пока не подтверждены.
Полный объём: VALIDATION-v3.1.4.md. Запрет mass apk upgrade сохраняется.
