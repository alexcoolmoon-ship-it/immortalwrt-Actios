ДЛЯ УЖЕ ПРОШИТОГО МОДЕМА UFI001C С РАДИО UFI001BC 20211121 / HW10000

1. Подключитесь к сети модема. Распакуйте весь архив.
2. Запустите APPLY.cmd. Введите SSH-пароль, если он запрошен.
3. LTE будет переподключён; оставьте питание, дождитесь окончания (обычно 4-7 минут).
4. Если SSH оборвался, подключитесь обратно и запустите CONTINUE.cmd.
   APPLY.cmd второй раз во время работы не запускайте.
5. Откроется папка с ufi-profile-report.tar.gz. Пришлите этот небольшой отчёт.

Это не перебор частот и не новая прошивка. Сохраняется маска
B1/B3/B5/B8/B38/B39/B40/B41, исключены только B7/B20, режим только LTE.
Скрипт проверяет плату/радио, список частот и хэш установленного netifd.
LAN/Wi-Fi, APN и прокси-ссылка не меняются. Flash/NV не записываются.

Старый network лежит только на модеме в /root/ufi-profile/run-*/network.backup.private.
Он не попадает в отчёт. Старый B1/B3/B7 автоматически не восстанавливается:
при RF-сбое или невосстановленной связи остаётся резервный B1/B3.
Это защитный резерв, а не доказательство, что остальные частоты неисправны.

Результаты:
PROFILE_APPLIED_CHECKS_OK — новая маска, минимум 2 минуты RF-наблюдения,
3 подряд успешные проверки DoH через прокси + DNS роутера, служебные загрузки.
PROFILE_APPLIED_PROXY_UNSTABLE — маска применена, но DNS/прокси/загрузки нестабильны.
FALLBACK_B1_B3 — новая маска не прошла проверку LTE, сохранён резерв B1/B3.
FALLBACK_SAVED_CONNECTION_NOT_CONFIRMED — резерв записан, связь не подтверждена.
PREFLIGHT_FAILED — конфигурация/версия не соответствует проверенному случаю,
изменения не начинались; нужен текст ошибки.

Один 504 повторяется проверкой. Только после трёх неуспешных проб разрешён
один restart существующего валидного sing-box. Шаблон не запускается,
прямой DNS вместо туннеля не включается. Полное исправление удалённого
XHTTP/CDN по этому скрипту не заявляется.

Перед стабильным релизом ещё нужны передача данных и длительная работа на
новой маске, затем испытание собранного образа. Это не подтверждение работы
всех частот, других базовых станций или другого стокового модема.
