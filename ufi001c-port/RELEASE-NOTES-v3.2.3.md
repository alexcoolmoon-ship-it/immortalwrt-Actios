# UFI001C v3.2.3 Clean

Исправлен запуск DNS Cloudflare: режим HTTPS через прокси больше не ошибочно
подавляет начальную синхронизацию часов. NTP использует буквальные IP и имеет
предел 10 секунд плюс 2 секунды на принудительное завершение. В образ явно
включён coreutils-timeout; наличие ARM64-бинарника проверяется до упаковки.
Недоступный NTP записывает предупреждение и не вешает запуск Podkop.

Начальное разрешение имён прокси возвращено на Яндекс 77.88.8.8 UDP:53,
как в раннем варианте. Для сетей с разрешённым только TCP добавлен выбор
«Протокол начального DNS Яндекса» в Podkop. Диагностика проверяет выбранный
протокол. Cloudflare 1.1.1.1 HTTPS остаётся через выбранную прокси-секцию;
автоматического перехода клиентского DNS на прямой Яндекс нет.

USB-комплект содержит CHECK-DNS.cmd. Он собирает новый UFI-DNS.txt: Яндекс
UDP/TCP, адреса прокси без раскрытия имён, фактический Cloudflare DoH через
прокси, локальный DNS, FakeIP, часы, BOOT_ID, память и признаки RF/OOM.
Проверка не меняет настройки и не перезапускает сеть или радио.

Сохранены XHTTP extra/header uplink/x-edge-data/chunk 4000, FakeIP-кэш и
ограничение LTE B1/B3/B5/B8/B38/B39/B40/B41 с исключёнными B7/B20.
В исходниках присутствуют проверенные исправления утилит репозитория;
Go-флаштул не заменяет штатный Python-установщик этого USB-комплекта.

База: OpenWrt 25.12.5, Podkop 0.7.24 и podkop-engine 1.13.21-r12.
Это персональный порт UFI001C. Сначала проверяются исходники и предварительный
ARM64-движок, после сборки — точный движок нового образа, ядро и rootfs.
Проверки и их пределы: VALIDATION-v3.2.3.md. Аппаратная приёмка остаётся pending
до испытания на модеме пользователя. Инструкция: INSTALL-RU.md.
