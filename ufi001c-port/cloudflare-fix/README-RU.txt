UFI001C — патч Cloudflare DoH 1.0 для v3.2.1 Clean

Распакуйте ZIP целиком. Подключите Windows 11 к Wi-Fi модема.
Запустите APPLY.cmd и введите пароль root модема, когда его попросит SSH.
Пароль вводится без отображения символов. Интернет на ПК для установки не нужен.

Патч возвращает прежний обход блокировок оператора:
  77.88.8.8 по TCP напрямую — только bootstrap для адресов прокси;
  1.1.1.1 по DoH — через существующую прокси-секцию Podkop.
Секция dns_only имеет приоритет, если она настроена; иначе выбирается первая
заполненная прокси-секция. Ваши ссылки, списки, XHTTP-параметры сохраняются.

Меняется только программа Podkop и её DNS-настройки. Перезапускается только
Podkop/sing-box. Перепрошивки, перезагрузки модема, сброса Wi-Fi, смены LTE-бэндов,
нового watchdog и удаления FakeIP-кэша нет. B7/B20 остаются исключены.

PATCH_INSTALLED и CLOUDFLARE_DOH_PROXY=PASS означают, что патч установлен и
настоящий HTTPS DNS-запрос прошёл через выбранный прокси до Cloudflare.
FAIL не скрывается: патч остаётся установленным, запустите CHECK.cmd и пришлите
UFI-CLOUDFLARE.txt из открывшейся папки. Проверка не исправляет удалённый сервер,
если само VLESS/XHTTP-соединение недоступно. Проверка на модеме ещё необходима.

Резервная копия сохраняется только на модеме в /root/ufi-cloudflare-backup.*
и содержит ваши исходные настройки; её никому отправлять не нужно.
ROLLBACK.cmd восстанавливает эту копию. Изменения Podkop после установки патча
при откате заменяются сохранённой копией. CHECK.cmd настройки не меняет.

Патч проверяет точную версию и SHA256 исходного Podkop. На другой/изменённой
прошивке он прекращает установку до изменений. Если Windows пишет, что ключ SSH
модема изменился после перепрошивки, сверьте подключение с UFI001C; проверка ключа
SSH в скриптах не отключается.
