# UFI001C v3.2.0 Final Candidate / Portable USB

Подготовка финальной сборки после проверки LTE-профиля 18 октября 2026.
OpenWrt 25.12.5, Podkop 0.7.24 и podkop-engine 1.13.21-r12 остаются зафиксированными.

- Включены пропущенные в публичной ветке исправления v3.1.6: jq без regex,
  IPv4-состояние LTE, двухдиапазонные исключения, защита DNS/FakeIP, проверки CI.
- Чистая установка использует точную проверенную маску LTE-only
  B1/B3/B5/B8/B38/B39/B40/B41. Нет автоматического добавления новых диапазонов.
- Добавлено обезличенное свидетельство проверки текущей загрузки: LTE, DoH и DNS 3/3.
  Оно не считается аппаратной проверкой образов v3.2.0.
- После сообщения об отказе DNS при 4К-нагрузке исправлена ложная успешность
  локальной проверки: SERVFAIL/REFUSED и пустой ответ теперь считаются ошибкой.
  Bootstrap использует TCP к тому же серверу; UDP остаётся явной настройкой.
- Добавлен контроль реального DoH через выбранный прокси и обоих локальных DNS.
  После трёх неудачных проверок при исправном LTE перезапускается только sing-box
  либо только dnsmasq. Пауза минимум 300 секунд, максимум три попытки за час.
  Остановка пользователем, смена конфигурации и сбой LTE отменяют восстановление.
  В RAM сохраняются ресурсы, число сокетов и conntrack перед попыткой; CHECK-LTE
  включает этот снимок. Корневая причина исходного обрыва по фото не установлена.
- USB-ZIP включает переносимые Windows-программы: Python и EDL уже внутри.
  INSTALL.cmd предпочитает этот runtime, старое рабочее EDL-окружение остаётся
  запасным способом для исходников. Пользовательские команды Python/Git не нужны.
- EDL и установщик собраны отдельными EXE. Однокаталожная упаковка не распаковывает
  среду заново при каждом блочном чтении. Включены только закреплённые MSM8916 loaders.
- Источники EDL и Loaders зафиксированы по полным Git SHA; проверяются также хэши
  входных файлов. Python-зависимости EDL берутся из его uv.lock с хэшами.
- Перед первым EDL-чтением проверяется наличие ровно одного 05C6:9008.
  Подготовлены CHECK-PC.cmd и DRIVER-HELP.cmd с включённым Zadig; установка
  WinUSB на новом ПК выполняется пользователем, без подмены других устройств.
- Полный бэкап, возобновление, собственные NV, привязка к экземпляру,
  обратное чтение записей и GPT последней сохранены. Неизвестное радио не разрешено.
- Windows CI выполняет реальный запуск EXE без USB, включая EDL --help и DLL/backend;
  каталог с пробелами/кириллицей используется при тестировании. Linux-упаковка
  проверяет соответствие runtime тому же коммиту и тем же исходникам установщика.
- CHECK-LTE.cmd всегда собирает свежий отчёт. Live-fix wait после смены boot ID
  возвращает отдельный код ошибки вместо бесконечной повторной выдачи старого отчёта.
- Готовые образы и EXE создаёт только успешный workflow. До первого реального
  прохождения установки нового образа со стока публикация остаётся Pre-release.

Не устранены по имеющимся данным: причина прежней перезагрузки, аппаратная
кнопка на всех платах, длительная устойчивость и возможные отказы удалённого XHTTP/CDN.
Не обещаны AP+STA, работа всех диапазонов при регистрации или фиксированное время прошивки.
