UFI001C: проверка DNS 1.0

Для v3.2.1 с Cloudflare-патчем и v3.2.2. Прошивка и установка не требуются.

1. Распакуйте архив целиком на компьютере Windows.
2. Подключите компьютер к Wi-Fi модема.
3. Пока в Podkop красные проверки, запустите CHECK.cmd.
4. Введите пароль root модема при запросе SSH.
5. В открывшейся папке будет UFI-DNS.txt. Отправьте этот файл.

Снимок лучше сделать до перезагрузки/перезапуска Podkop, чтобы сохранить
состояние неисправности. Проверка обычно занимает меньше минуты; при
нескольких прокси и сетевых таймаутах может занять дольше.

Скрипт не меняет UCI, DNS, Wi-Fi, LTE, бэнды, правила firewall или кэш FakeIP.
Он не перезапускает службы и не запускает второй движок.
Создаёт только собственные временные файлы и удаляет их после проверки.
Прямые DNS-пробы идут только к Яндексу 77.88.8.8; Cloudflare проверяется
через существующий локальный прокси Podkop, с проверкой TLS.

В отчёте: время/boot_id, память, LTE-интерфейс, пробы Яндекса TCP/UDP,
разрешение имён прокси без раскрытия самих имён/IP, ошибка curl к Cloudflare,
локальный DNS/FakeIP и строки ядра о RF/OOM. Полная конфигурация, URL/UUID,
APN, IMEI/IMSI и пароли не собираются. Логи sing-box выводятся только счётчиками.

SSH_EXIT=0 означает завершение сбора, а не исправность сети.
Результаты смотрятся по отдельным PASS/FAIL в отчёте.
