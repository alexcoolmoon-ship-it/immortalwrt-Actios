# UFI001C OpenWrt 25.12.5 — v3.1.2 Setup

Персональная сборка alexcoolmoon-ship-it для проверяемого профиля **UFI001C 8 ГБ / UFI001BC 20211121**.

Скачайте **UFI001C-OpenWrt-25.12.5-v3.1.2-USB.zip** в Assets, распакуйте и откройте
`UFI001C-USB/INSTALL.cmd` для перехода со стока. В архиве уже есть прошивка и
установщик. Стандартные ссылки GitHub «Source code» содержат исходники, не прошивку.
На новом Windows-ПК предварительно нужен Python/EDL с USB-драйвером; подробности
в `README-STOCK-RU.md`. Подключайте один модем; полный бэкап сохраняется отдельно
в `%USERPROFILE%\UFI001C-backups`.

Для уже установленного OpenWrt применяется обновление из `INSTALL-RU.md`,
а не стоковый `INSTALL.cmd`. Это не файл для загрузки в заводскую веб-панель.

В этом выпуске:

- Исправлено добавление секции Podkop после удаления последней. Имя `dns_only`
  не обязательно; DNS и списки автоматически выбирают заполненный одиночный прокси.
- Пустые секции не ломают запуск заполненных; без настроенного прокси сохраняется
  обычный DNS. Приватная прокси-ссылка вводится владельцем после установки.
- FakeIP проверяется локально во всём диапазоне `198.18.0.0/15`. Недоступность
  внешнего тестового сайта показывается отдельно и не маскируется успешным результатом.
- Сохранены XHTTP r12, IPv4 policy routing, радио и механизм восстановления сети.

CI проверил образы, содержимое rootfs, параметры ядра и настоящий ARM64-движок
через QEMU. Отчёты и контрольные суммы включены в архив. Публикация помечена
**Pre-release**, пока именно этот образ не прошёл приёмку на устройстве: LTE,
HTTPS через Podkop, повторное включение питания, кнопка и восстановление Wi-Fi.
CI не проверяет доступность вашего прокси-сервера, SIM и работу физической кнопки.

Инструкция и исходники находятся в `ufi001c-port/` этого репозитория.
