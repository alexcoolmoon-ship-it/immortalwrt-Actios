## Новое требование и выполненные изменения

Скриншот: XHTTP не поддерживается установленным sing-box, требуется
podkop-engine r11+. Причина установлена. В исходники v3 включён движок
FiyeroT/podkop-engine 1.13.21-r12, 86 патчей, Go 1.26.8, Podkop 0.7.23.
Не удалять проверку поддержки XHTTP и не возвращать обычный sing-box.

Подготовлен Windows stock_install.py 3.0-rc1: INSTALL.cmd, полный бэкап вне
папки программы, точный заводской профиль, собственные NV, запись с обратным
чтением. RESTORE.cmd восстанавливает только свой заводской бэкап. MAKE-BUNDLE
принимает теперь только новый v3 XHTTP с привязанным отчётом проверки.
Это USB/EDL, формат заводского веб-обновления не подтверждён.

Установщик 2.1 обслуживает уже установленный OpenWrt: только rootfs и boot.
Он понимает fwtool metadata и выравнивает отдельную копию boot, не меняя
оригиналы и SHA256SUMS. Не добавлять нули и не редактировать хеши вручную.
