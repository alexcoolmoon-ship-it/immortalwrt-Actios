# UFI001C v3.1.3 Stability — кандидат

Изменения по журналам от 11 октября 2026:

- USB: обработчик `hotplug-gcreboot` больше не перезапускает USB-гаджет
  автоматически по событию USB=0. На новой системе `gc.config.auto_restart=0`.
  Для явного включения остаются блокировка параллельных запусков и интервал 60 с.
- DNS: поддержаны заполненные Selector и URLTest, включая вложенную группу,
  которую создаёт Podkop, и резервные серверы движка r12. DNS и списки идут
  через выбранную группу; имена её серверов разрешаются bootstrap DNS.
  Сохраняются UUID, TLS, XHTTP и настройки выбора сервера. Прямые выходы,
  циклы, отсутствующие серверы и цепочки detour не допускаются для DNS.
- Сток: к профилю 8 ГБ добавлен точный профиль 4 ГБ из присланного GPT.
  Одинакового имени платы недостаточно: требуются совпадающий хеш радио,
  полный бэкап, сверка обеих GPT и индивидуальных NV перед записью.
- `STOCK-CHECK.cmd`: диагностика GPT/радио без прошивки и без чтения NV.
- `ufi-stability-report`: идентификатор загрузки, время работы, состояние AP,
  счётчик пересозданий USB и относящиеся к проблеме события.
- Проверка rootfs теперь проверяет и новые файлы USB/диагностики.

Остаются включёнными Podkop 0.7.23, podkop-engine 1.13.21-r12 с XHTTP,
радио UFI001BC 20211121, исправления IPv4/FakeIP и создание секций из v3.1.2.

Это исходники кандидата, а не заявление об аппаратной стабильности. Новый
образ должен пройти Actions и проверку на конкретном модеме. Работу прокси
с ошибками удалённого HTTP/2 peer нельзя подтвердить локальными тестами.

Для установки из успешного выпуска нужен один `*-v3.1.3-USB.zip`, распаковка
и `INSTALL.cmd` на Windows-ПК с рабочим EDL. Загрузка этого ZIP в заводскую
веб-панель не поддерживается. [Инструкция](INSTALL-RU.md).
