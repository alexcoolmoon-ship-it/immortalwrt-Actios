# Переход со стока через веб-интерфейс: статус

Пакет для загрузки в заводскую веб-панель пока не создан. USB-ZIP, boot.img
и system.img не являются подтверждёнными заводскими OTA-пакетами.

В имеющихся исходниках установлен точный профиль второго модема:
UFI001C, eMMC 4 ГБ, известная разметка и радио UFI001BC 20211121.
Это подтверждает профиль для проверки USB-установщиком, но не формат веб-обновления.

Текущий переход меняет таблицу GPT и загрузочную цепочку, переносит собственные
NV-разделы устройства и только затем переключает разметку. Упаковка boot.img
и system.img в ZIP сама по себе не делает эту операцию совместимой с заводским
обновлятором. Нельзя подменять радиокалибровки копией от другого экземпляра.

Для разработки веб-перехода нужен оригинальный файл обновления именно этой
заводской прошивки либо её обработчик обновления и recovery. По ним необходимо
установить формат пакета, проверку подписи/модели, допустимые разделы и доступный
режим выполнения миграции. Затем — проверенный личный полный бэкап, восстановление
через EDL и аппаратный тест на подходящей ревизии. Неполный emmc.partial не является
копией для восстановления. Ранее имевшаяся ошибка USB-чтения этим CI-патчем не лечится.

Следующий входной материал: оригинальный заводской файл обновления для нового
модема и фото страницы «Обновление ПО», где видны версия и допустимый тип файла.
Если заводского файла нет, сначала достаточно фото этой страницы; после него
можно выбрать конкретный способ чтения обработчика без записи в модем.
Ссылку с паролем, IMEI, ключи VPN и полный приватный дамп публиковать в GitHub не нужно.

Для уже установленного OpenWrt текущая функция platform_check_image также
отклоняет sysupgrade: она рассчитана на отдельные Android boot/rootfs образы.
Поэтому обновление из LuCI и переход из заводской панели — две разные задачи,
ни одна не становится готовой от исправления GitHub Actions.

Основания: stock_install.py::make_plan и
overlay/target/linux/msm89xx/base-files/lib/upgrade/platform.sh в этом проекте;
описание замены GPT/загрузчика у OpenStick: https://github.com/OpenStick/OpenStick.
