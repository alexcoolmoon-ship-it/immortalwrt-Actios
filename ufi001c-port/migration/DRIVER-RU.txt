USB-ДРАЙВЕР: ОДИН РАЗ НА НОВОМ WINDOWS-ПК

Python, EDL и USB-библиотека уже включены в полный USB-ZIP.
Если этот ПК уже прошивал модем через EDL, сначала попробуйте INSTALL.cmd.

Если EDL 05C6:9008 не найден или Windows не даёт к нему доступ:
1. Оставьте подключённым только один модем. Подключите его с зажатой кнопкой,
   затем отпустите её. В Диспетчере устройств должен появиться Qualcomm 9008.
2. Запустите DRIVER-HELP.cmd. Откроются эта инструкция и Zadig.
3. В Zadig выберите Options -> List All Devices.
4. Выберите именно модем. Проверьте USB ID: 05C6 9008.
5. Справа выберите WinUSB и нажмите Install Driver / Replace Driver.
   Подтвердите запрос администратора Windows.
6. Закройте Zadig и повторите INSTALL.cmd.

Драйвер выбирается только для EDL 05C6:9008. Остальные устройства не выбирайте.
После прошивки модем сменит USB-режим; его обычный сетевой интерфейс — другое
устройство. INSTALL.cmd не меняет драйверы автоматически.

Источник EDL и включённого Zadig указан в runtime/runtime-manifest.json.
Документация: https://github.com/bkerler/edl#installation
WinUSB: https://github.com/libusb/libusb/wiki/Windows
