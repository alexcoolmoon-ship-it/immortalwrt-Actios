# UFI001C → OpenWrt 25: установка через один запуск

Версия установщика: **3.0-rc1**. Нужна новая успешная сборка **v3 XHTTP**.
В ней podkop-engine 1.13.21-r12 уже включён в образ. Запуск предыдущей v2
подтверждён пользователем; автоматический переход RC1 со стока пока проверен
на программной модели памяти, а не на втором физическом модеме.

## Что требуется

- Именно плата **UFI001C**, известная заводская разметка eMMC 8 ГБ и радио
  UFI001BC 20211121. Корпус и надпись «Qualcomm 410» не определяют совместимость.
  При другом профиле установщик остановится до записи.
- Тот Windows-ПК, где уже работает EDL: `%USERPROFILE%\edl`.
  Python, EDL и USB-драйвер используются из существующей установки.
- Не менее **12 ГБ** свободного места для прошивки с бэкапом.
- ZIP успешной сборки **v3 XHTTP**:
  `boot.img`, `system.img`, `SHA256SUMS`, `build.config`, `ACCESS.txt`,
  `xhttp-validation.json`. Отчёт должен относиться именно к этим образам.
  ZIP с исходным кодом, build-log или установщиком для этого не подходят.

## Один раз: получить единый архив с прошивкой

1. Распакуйте этот комплект на ПК.
2. Откройте **MAKE-BUNDLE.cmd** и выберите ZIP успешной сборки v3 XHTTP.
3. В «Загрузках» появится **UFI001C-OpenWrt25-USB-3.0-rc1.zip**.

Это проверка и упаковка уже готовых файлов, а не новая сборка ядра.
В едином архиве есть прошивка, программа установки и возврат к стоку.
Бэкапы и индивидуальные NV туда не добавляются. Wi-Fi-пароль из ACCESS.txt
одинаков для экземпляров, установленных из одного такого архива.

## Каждый следующий стоковый модем

1. Распакуйте единый архив и запустите **INSTALL.cmd**.
2. Оставьте подключённым только один модем. По подсказке программы отключите
   его, зажмите физическую кнопку, подключите к USB ПК и отпустите кнопку.
   Нажмите Enter. Начнутся чтение и проверка заводской памяти.
3. После сохранения бэкапа проверьте показанный профиль. Для записи введите
   **UFI001C**. Подождите окончания записи и проверки обратным чтением.
4. После сообщения об успешной проверке переподключите USB **без кнопки**.
   Подождите 2–3 минуты, подключитесь к Wi-Fi из открывшегося ACCESS.txt.
   Панель: **http://192.168.1.1**.

Можно пропустить MAKE-BUNDLE.cmd: обычный INSTALL.cmd сам предложит выбрать
ZIP прошивки, если образы ещё не лежат рядом с ним.

Бэкап сохраняется в **`%USERPROFILE%\UFI001C-backups\дата-время\emmc.bin`**,
вместе с `install.json` и журналом. Папка отдельная от установщика.
Сохраните её целиком: копия содержит заводскую систему и личные данные модема.

## Если запись остановилась / возврат к стоку

Оставьте устройство в EDL или подключите заново с кнопкой. Запустите
**RESTORE.cmd**, выберите `emmc.bin` этого модема, затем введите **RESTORE**.
Программа сверит принадлежность копии по сохранённым областям NV, восстановит
всю память и прочитает её обратно для сравнения. Для этой проверки нужно ещё
9 ГБ свободного места. При успешном результате переподключите USB без кнопки.

Если другая программа уже перезаписала исходные области NV, автоматическое
сопоставление может не пройти. Обхода этой проверки в комплекте нет.

При ошибке сохраните `edl.log` и `install.json`. Не редактируйте SHA256SUMS,
не дописывайте нули в boot.img и не меняйте исходные образы вручную.
Исправления выравнивания и разбора OpenWrt metadata уже встроены.

## Пределы этой версии

- Это USB-установка. Наши boot.img/system.img не являются подтверждённым
  пакетом обновления заводской веб-панели. В её Upload их не отправлять.
- На текущий работающий OpenWrt этот установщик со стока запускать не нужно:
  он отклонит другую разметку. Для существующего OpenWrt остаётся обновление 2.1.
- Аппаратный приёмочный тест RC1: загрузка второго модема, LTE с его SIM,
  Wi-Fi/LuCI, кнопка восстановления и возврат AP после неудачного Wi-Fi-клиента.
  До этого результат не называется испытанным финальным релизом.
- Возможности радио и AP+STA эта упаковка не меняет. Кнопка и возврат Wi-Fi
  используют включённый в образ ufi-care. Zapret требует стратегии оператора;
  пользовательский прокси Podkop в прошивку не добавлен.
- На новом ПК понадобится однократная установка Python/EDL и подходящего
  USB-драйвера: https://github.com/bkerler/edl#installation . Драйверы и Python
  этот комплект автоматически не устанавливает. На вашем настроенном ПК
  повторять это не требуется. Для другого пути задайте переменную UFI_EDL_ROOT.

## Исходники и автоматическая упаковка

В комплекте исходников папка `github-update` содержит изменения для репозитория.
Новый workflow **Build UFI001C USB installer** собирает только установщик,
без компиляции OpenWrt. Обновлённый основной workflow кладёт INSTALL.cmd и
RESTORE.cmd прямо в будущий артефакт прошивки. Для XHTTP нужна новая сборка v3; прежний образ v2 этой проверки не пройдёт.
