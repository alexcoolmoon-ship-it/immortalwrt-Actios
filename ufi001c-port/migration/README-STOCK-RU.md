# UFI001C: простой переход со стока — v3.2.1 Clean

Нужен **полный USB-ZIP успешной сборки** для Windows 10/11 x64. В нём уже лежат
образы, переносимый установщик, Python-окружение, EDL и USB-библиотека.
Установка Python, Git и EDL пользователем не требуется. Интернет во время
прошивки для подготовки инструментов не используется.

## Четыре шага

1. Распакуйте `UFI001C-OpenWrt-25.12.5-v3.2.1-USB.zip` целиком.
2. Запустите **INSTALL.cmd**. По подсказке подключите один модем с зажатой
   кнопкой и отпустите её. Нажмите Enter.
3. Программа проверит разметку и радио, сохранит полный бэкап и проверит его.
   Для начала записи введите **UFI001C**. Дождитесь проверки обратным чтением.
4. Переподключите модем без кнопки, подождите 2–3 минуты первого запуска.
   Откройте Wi-Fi из **ACCESS.txt**, затем **http://192.168.1.1**.

На новом ПК USB-драйвер может понадобиться один раз: **DRIVER-HELP.cmd** открывает
Zadig и инструкцию. Выбирается только EDL-модем с ID **05C6:9008**, драйвер **WinUSB**.
Администратор Windows подтверждает эту установку. Никакие драйверы других устройств
установщик не меняет. **CHECK-PC.cmd** проверяет комплект программ без подключения модема.

## Что сохраняется и проверяется

Бэкап и журнал: **`%USERPROFILE%\UFI001C-backups\папка-запуска`**.
Храните всю папку. Заводские индивидуальные NV берутся только с этого экземпляра.
Радио и геометрия проверяются до большого бэкапа, неизвестная ревизия отклоняется.
Полный бэкап читается блоками с контрольными точками. Запись начинается только
после его успешной проверки и подтверждения пользователя. Каждый записанный
участок читается обратно; смена GPT выполняется последней.

Разрешены две точные заводские разметки eMMC 4/8 ГБ и известный хэш радио
UFI001BC 20211121. Совпадения корпуса, названия или текста версии недостаточно.
Другие радиодампы не разрешены этой правкой автоматически.
Для подготовки и проверки образов с бэкапом понадобится до 12 ГБ свободного места.
Полный бэкап — основной объём передачи, скорость USB/eMMC заранее не гарантируется.

## Обрыв чтения

Если запись ещё не началась, переподключите тот же модем в EDL и запустите
**RESUME.cmd**, выбрав `backup-state.json` из сохранённой папки. Уже проверенные
блоки не читаются повторно с устройства; их локальные данные и принадлежность
модему проверяются. Частичный `emmc.partial` не считается готовым бэкапом.

## Возврат к стоку

Запустите **RESTORE.cmd**, выберите собственный `emmc.bin`, подключите этот модем
в EDL. После проверки принадлежности копии введите **RESTORE**. Восстанавливается
весь дамп с последующим полным чтением обратно. Нужны место под проверочную копию
и сохранённый `install.json`. Чужой бэкап и повреждённые контрольные точки отклоняются.

**STOCK-CHECK.cmd** только читает разметку/радио, **CHECK-BACKUP.cmd** проверяет
уже сохранённый emmc.bin без USB и создаёт небольшой `ufi-stock-radio.zip`.
При остановке сохраните текст ошибки и папку журнала. Полный дамп с NV не публикуйте.

## После запуска OpenWrt

Режим LTE и маска B1/B3/B5/B8/B38/B39/B40/B41 заданы при первом запуске.
Введите свою ссылку в Podkop → Секции, сохраните и запустите Podkop.
Для свежего отчёта запустите **CHECK-LTE.cmd**. Он проверяет текущую загрузку,
не меняет настройки и открывает папку с `ufi-postboot-report.tar.gz`.

Этот установщик предназначен для перехода со стока. Обновление действующего
OpenWrt описано в INSTALL-RU.md. Совместимость с заводским веб-обновлением не заявляется.
Новый образ и переносимые EXE проходят CI; аппаратная приёмка перехода со стока
на дополнительном экземпляре ещё необходима. Полный комплект публикуется как Pre-release.
