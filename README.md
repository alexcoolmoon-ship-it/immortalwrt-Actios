# UFI001C · OpenWrt 25.12.5 · v3.2.1 Clean

Минимальная персональная сборка UFI001C на официальных исходниках OpenWrt 25.12.5
и Podkop 0.7.24. Поддержка самой платы — отдельный порт, не официальный образ OpenWrt.
Для XHTTP оставлен podkop-engine 1.13.21-r12: обычный sing-box этот транспорт не поддерживает.

В образе: LTE, Wi-Fi, USB Ethernet, LuCI на русском, штатный интерфейс Podkop.
DNS и bootstrap идут напрямую по TCP к 77.88.8.8, без зависимости от XHTTP.
FakeIP, кэш и маршрутизация Podkop сохранены. DoH/DoT можно выбрать в настройках.

Убраны ufi-care, ufi-lte-health, DNS-watchdog, Zapret, прокси-обёртки APK/wget,
изменения LuCI и отдельный failsafe движка. Исходники старых профилей остаются
в репозитории для истории; prepare_clean.py исключает их из этой сборки.

Полный USB-ZIP включает переносимые программы Windows и EDL. Для стока:
распаковать целиком, запустить INSTALL.cmd, дождаться бэкапа и проверки записи.
Для уже установленного OpenWrt используется отдельная процедура обновления.

LTE-профиль прежний: B1/B3/B5/B8/B38/B39/B40/B41; B7/B20 исключены по данным
предыдущих аппаратных проверок. Драйверы, радио и индивидуальные NV не заменены.

Сборка проходит проверки исходников, установщика, ядра, состава rootfs и ARM64-движка.
Проверка длительного видео, DNS и неизменного boot_id на самом модеме ещё требуется.
